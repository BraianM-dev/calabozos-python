Un mismo recorrido, distintas historias

Las tres campañas utilizan las mismas 39 actividades, validaciones reales de Python, progreso, borradores, Pip, accesibilidad y ficha de personaje. Podés cambiar de campaña sin reiniciar XP ni misiones.

  • Python real: print, input, variables, operadores, condicionales, bucles, listas, diccionarios, funciones, random y errores.
  • Gamificación: escribir, completar, ordenar, predecir, depurar y superar retos finales.
  • Pip contextual: tutor ilustrado con andamiaje fuerte y estados visuales según cada situación.
  • PDF temático: la ficha cambia automáticamente entre Aventura, Arcana y Multiverso.
  • Accesibilidad: contraste, tamaño de texto, lectura fácil y reducir movimiento.
  • CREA / GitHub Pages: funcionamiento estático, responsive, iframe y recursos locales para modo offline.
