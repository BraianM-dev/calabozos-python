CALABOZOS & PYTHON

Campaña RPG para aprender los fundamentos de Python

¿Cómo se escribe un programa? ¿Qué es una variable? ¿Cómo toma decisiones una computadora? ¿Cómo se repiten acciones o se organizan datos? ¿Qué pasa cuando el programa falla?

Este recurso invita a los estudiantes a responder esas preguntas jugando. A través de un mapa de calabozos, misiones narrativas y un asistente llamado Pip el Ayudante, los alumnos practican Python de forma progresiva, con pistas y feedback inmediato.

⚔ Entrar al Calabozo Cómo está organizado

Preguntas para empezar a pensar

Antes de entrar, reflexionemos:

¿Qué pasos seguirías para preparar un mate? ¿Eso es un algoritmo?
Si el orco tiene más de 20 de vida, ¿atacás o huís? ¿Cómo le explicarías eso a una computadora?
¿Cómo guardarías la lista de objetos de tu mochila? ¿Y los datos de un monstruo (nombre + vida)?
¿Qué pasa si el programa intenta dividir por cero o usa una variable que no existe?

Estas preguntas se responden a lo largo de las misiones del calabozo.

Cómo está organizado el recurso

01

La Taberna del Inicio · print()

Mostrar mensajes. Primer contacto con la salida de datos.

02

La Puerta del Calabozo · input()

Pedir datos al usuario, guardar en variables y convertir con int().

03

La Ficha del Héroe · Variables y tipos

Guardar datos. Texto, números enteros (int), decimales (float) y booleanos.

04

La Balanza · Operadores y tipos

Cuentas, módulo % y comparaciones (>, ==…).

05

La Encrucijada · Condicionales y lógica

Tomar decisiones con if / elif / else, and, or, not.

05

El Ataque Múltiple · Bucles

Repetir acciones con for y while.

06

La Mochila · Listas

Colecciones ordenadas, recorrido, append e índices.

07

El Grimorio · Diccionarios

Pares clave-valor para representar datos estructurados.

08

El Libro de Hechizos · Funciones

Crear bloques reutilizables con def, parámetros y return.

09

El Dado Mágico · random + errores

Azar con el módulo random y manejo básico de errores (try/except).

+

Misión Secreta · Mini Chatbot + Dragón final

Aplicar todo lo aprendido en un chatbot y el combate final.

Características pedagógicas

  • Progresión por sub-niveles: 2–3 desafíos por tema.
  • Validación real del código (intérprete Python en el navegador).
  • Pip el Ayudante: explica conceptos (variable, algoritmo, int, float, try/except…) y analiza código incompleto sin regalar soluciones.
  • Pistas progresivas y checklist de diagnóstico.
  • Diseño Universal para el Aprendizaje (DUA).
  • Accesibilidad: tamaño de letra, contraste, dislexia, reducción de movimiento (epilepsia).
  • Exportación de hoja de avance en PDF.
  • Funciona offline y se puede embeber con iframes.

Cómo se usa en el aula

  1. Los estudiantes escriben su nombre y apellido y eligen una clase (Mago, Guerrero, Arquero o Explorador).
  2. Avanzan por el mapa resolviendo las misiones en orden.
  3. Si se traban, abren el chat de Pip y preguntan conceptos o mandan fragmentos de código.
  4. Al completar temas desbloquean objetos de inventario y pueden enfrentar misiones bonus.
  5. Al final pueden exportar su hoja de personaje con el sello de progreso.

El recurso puede usarse en computadora de aula, notebook personal o embebido en un LMS / aula virtual mediante iframe.
